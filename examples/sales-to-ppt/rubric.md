# 质量验收量表草案

状态：未完成真实样本校准。当前先指定人工复核，未来模型评分器须对人工标注集评估误放行、误拒绝与分歧，达到约定门槛后才可接替。评分依据是实际分析和 PPT 渲染。

<a id="claim-grounding"></a>
## 结论依据（C04）

| 分数 | 标准 |
|---|---|
| 4 | 所有数值结论可对应输入/分析字段；贡献与因果明确区分；假设与限制清楚 |
| 3 | 无已发现错误，但部分引用无法追溯或限制说明不充分 |
| 2 | 多处缺依据，贡献解释含混 |
| 1 | 核心结论与数据冲突或把未证实因素写成确定原因 |
| 0 | 无有效分析、仅关键词堆砌或内容不相关 |

阈值为 4。已确认的虚构事实或不支持的因果断言直接失败；证据采集不完整时返回 UNKNOWN，而非假定论述正确。保留逐条引用和理由。

<a id="presentation-quality"></a>
## PPT 质量（C08）

| 分数 | 标准 |
|---|---|
| 4 | 五页主题完整，信息层级清楚，图表标签/单位齐全，全部页面清晰可读 |
| 3 | 主题完整且可读；仅有不影响理解的轻微视觉问题 |
| 2 | 缺少主题或存在影响理解的标签、布局问题 |
| 1 | 主要信息被截断、遮挡或无法阅读 |
| 0 | 没有可供评价的有效内容 |

阈值为 3。任何遮挡/截断导致关键结论不可读，或关键图表缺标签/单位，直接失败。没有渲染证据且无法判断时返回 UNKNOWN；渲染器故障返回 ERROR；收集完整且确认未交付文件由交付检查判 FAIL。
